## Что реализую (3 блока)

### Блок A. Уведомления + бейдж (G1+G2)
Виртуальный центр уведомлений на основе поллинга `GET /chains/my` (бэка уведомлений/ws нет).

- **Новый слой:** `entities/notification/` — НЕ новый эндпоинт, а **фабрика событий** из `TChain` (pure-функции в `lib/`): тип события (`incoming_offer | status_changed`), иконка, текст, ссылка. Никаких вызовов бэка сверх `getMyChains`.
- **Новый хук:** `widgets/headerMenu/lib/useNotifications.ts` — `useGetMyChainsQuery(..., { pollingInterval: 30_000 })`, производная событий, счётчик активных входящих (`status∈{pending,countered}` И `initiator_id !== me`). «Прочитано» — best-effort в `localStorage` (с `chain_id`-ключами), т.к. поля `read`/`recipient_id` в типе нет.
- **Новый компонент (1 файл):** `widgets/headerMenu/ui/notificationBell/NotificationBell.tsx` — иконка-колокольчик + бейдж (BEM `notification-bell__badge`), ссылка на `/notifications`.
- **Новая страница:** `pages/notifications/` — `NotificationsPage.tsx` (список событий → клик открывает `/exchanges/:chainId`), `lib/useNotificationsPage.ts` (сетит `usePageTitle('Уведомления')`, гостевой гейт, loading/error/empty).
- **Маршрут:** добавить `/notifications` в `app/router/routes.tsx` (lazy).
- **Шапка:** вставить `<NotificationBell />` в `DesktopHeaderMenu` (и мобильный аналог) рядом с «Обмены»; бейдж на «Обмены» (counter).

### Блок Б. Профиль: отзывы + история обменов (G4+G5)
Профиль сейчас бедный — только товары и счётчик отзывов.

- **`useProfile.ts` (расширить):** добавить `useGetMyChainsQuery` → моя история сделок (резолв товаров по `getProducts`), `reviews` — полный список (`getReviewsByCustomer` уже есть, отдаю массив вместо только длины). Новые поля: `exchanges`, `reviews`.
- **`ProfileContent.tsx` (расширить):** новая вкладка «Отзывы» (карточки отзывов: рейтинг `Rating` + дата + комментарий) и вкладка «Мои обмены» (переиспользую компактную строку `ProductThumb→ProductThumb` + `StatusBadge` → `/exchanges/:id`). Тип `TProfileTab` расширяю до `'active' | 'archived' | 'exchanges' | 'reviews'`.
- **Новый переиспользуемый компонент:** `shared/ui/reviewCard/ReviewCard.tsx` (1 файл, BEM) — чтобы и в карточке товара, и в профиле показывать отзывы одинаково.

### Блок В. Управление товаром + онбординг (G6+G8)

- **Снять с обмена / удалить:** на своей карточке товара (`ProductPage`, блок владельца) добавить меню/кнопки: «Снять с обмена» (`updateProduct { status: 'archived' }`) и «Удалить» (`deleteProduct`, `useDeleteProductMutation` уже есть, UI отсутствует) с подтверждением. Логика — в новом хуке `pages/product/lib/useProductActions.ts`.
