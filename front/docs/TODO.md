### Отсутствующий функционал (must/should по кейсу)
- **Нет эндпоинта рекомендаций/матча** (US-8 прямые рекомендации). `/products/{id}/recommendations`
  закомментирован.
- **Нет настоящего counter-offer** — «встречное предложение» (US-13) меняет только
  статус `countered` без payload. Условия можно передать лишь текстом в чат.
- **Нет уведомлений/WebSocket** (US-17) — фронт поллит `GET /chains/my`.
- **Нет доплаты** как данных/платежа (US-6, could/should) — `price` есть, но
  семантики «доплата за обмен» нет.
- **Нет имени/аватара/рейтинга на пользователе** — рейтинг считается через
  `GET /reviews/by-customer/{id}/rating`, имя = email.
